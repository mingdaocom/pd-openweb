# 登录页回归测试

在仓库根目录执行：

```bash
node --test src/pages/AuthService/login/index.test.js
```

测试维护在 `index.test.js`，执行真实的 `index.jsx` 初始化逻辑和 `util.js` 登录回调，以可控接口响应和内存存储验证自动登录回退。目前需要手动执行，未接入 CI。

覆盖平台账号和域账号自动登录失败后的企业配置恢复、账号回填与缓存清理；配置加载期间的 loading 状态；网络异常时保留自动登录缓存；自动登录成功、缓存过期、平台登录入口及 `systemLogin` 参数限制。

同时覆盖普通登录、自动登录业务失败和请求异常后的配置请求失败：企业配置失败展示默认登录页，SSO 配置或名称翻译失败时保留已获取的企业配置与单点登录限制。

账号切换覆盖平台账号与域账号：请求异常后，手动登录勾选自动登录时替换缓存，未勾选时清除旧缓存；自动登录成功时保留缓存；手动登录进入两步验证或企业单点登录流程时，同样按明确的未勾选状态清理旧缓存。

测试验证初始化状态、登录回调及请求分支，不替代客户环境的浏览器及真实认证接口联调。
