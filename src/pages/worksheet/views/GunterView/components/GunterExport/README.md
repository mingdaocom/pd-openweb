# 甘特图图片导出

工具栏保存当前已生效的查询条件和快速筛选快照，通过独立导出 ID 传递给导出页。
导出页等待工作表及默认筛选初始化完成后恢复快照，再查询数据并生成图片。

- 每次导出使用独立快照，有效期为 10 分钟，读取后删除；后续导出会清理过期快照。
- 空筛选也是有效快照，应覆盖视图默认条件。
- 快照失效、损坏或账号、应用、工作表、视图不匹配时停止导出。
- 未携带导出 ID 的旧地址保留默认筛选行为。
