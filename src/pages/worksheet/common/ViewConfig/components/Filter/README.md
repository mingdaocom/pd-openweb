# 视图过滤条件草稿回归测试

在仓库根目录执行：

```bash
node --test src/pages/worksheet/common/ViewConfig/components/Filter/index.test.js
```

测试与组件同目录维护，这是本模块的手工回归入口，当前未自动接入 CI。
通过 Babel 加载真实组件，以轻量 Hook 容器驱动渲染、effect 和事件；浏览器 UI、API 请求及条件格式化在边界替换。

覆盖自动刷新产生相同内容的新引用、后台配置更新、切换视图/工作表、取消、空条件、删除全部条件、保存失败重试、保存成功规范化结果，以及保存期间继续编辑和旧视图回调。
筛选器列表覆盖切表清空并关闭菜单、响应乱序、切回同表、空结果、过期请求失败、卸载清理，以及同表切换视图和刷新时不重复请求。
验证草稿、保存按钮状态、提交参数及内部编辑器的版本同步；不包含浏览器定时器、真实条件编辑器交互和服务端联调。
